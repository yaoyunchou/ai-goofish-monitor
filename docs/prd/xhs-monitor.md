# PRD：小红书公开商品监控

> **交付状态**：本期实现（2026-09-22）  
> **范围**：独立菜单。只采集公开商品页，不保存、不使用小红书登录态。  
> **不做**：飞书、MCP、自动拓店、智能去重、把闲鱼想要/浏览改成高水位。

## 1. 用户要什么

在现有闲鱼监控里单独看小红书商品的累计已售怎么变：今日、昨日、上小时，以及按小时/按日的增量。缺基线显示「—」，不写成 0。

## 2. 入口

- 侧栏独立分组「小红书」：商品看板 `/xhs`、添加商品 `/xhs/add`、店铺、商品详情 `/xhs/:productId`。
- 仍走本站登录。采集本身不需要小红书账号。

## 3. 验收

- 粘贴公开商品链接或商品 ID 可以加入监控，并可填写店铺、分类和标记。也可用 Excel 模板批量导入。
- 侧栏有店铺。按店看监控商品的累计已售合计，以及今日、昨日、上小时。
- 手动采集与独立 Cron 都能写入快照；快照只追加，同一小时也不覆盖。
- 看板展示累计已售（高水位）、今日、昨日、上小时。
- 单品页展示按小时、按近 7 日的增量；中途才开始监控的区间标「口径不完整」。
- 公开页要求登录或返回 461 时记失败并停止本轮，不弹登录。
- 闲鱼日指标与健康度周差值保持原样。

算法对照见 [metric-delta-comparison.md](../design/metric-delta-comparison.md)。实现口径见 [xhs-monitor 设计](../design/xhs-monitor.md)。
