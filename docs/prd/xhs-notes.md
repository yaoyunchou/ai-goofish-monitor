# PRD：小红书笔记（增量）

> **交付状态**：本期实现  
> **提出日期**：2026-09-24  
> **类型**：简单增量 PRD（无竞品分析）  
> **对应设计**：`docs/design/xhs-notes.md`

## 1. 项目信息

| 项 | 内容 |
|----|------|
| 项目 | `ai_goofish_monitor` |
| 语言 | 中文 |
| 变更性质 | 笔记单独成菜单。商品公开页的采集方式不变 |

### 1.1 原始需求复述

笔记必须登录，不能像公开商品那样频繁打开。希望和商品看板分开，按闲鱼日指标那样每天只留一行，同一天再采覆盖当天。没有登录时不要打开浏览器。

## 2. 产品定义

### 2.1 目标

1. 侧栏「小红书」在商品看板下面增加「笔记」。
2. 商品添加遇到笔记链接时不写入商品表，并说明请到笔记菜单添加。
3. 每天每个笔记一行，记录点赞、收藏、评论；页面没有浏览数就空着。
4. 默认定时每天一次，默认不启用。笔记之间串行，间隔 3 秒。
5. 没有可用的小红书登录时，本轮不打开浏览器。

### 2.2 用户故事

1. 作为运营者，我希望笔记和商品分开看，避免笔记链接进商品失败列表。
2. 作为运营者，我希望同一天多次采集只更新当天数字，缺的字段不要把已有数字清掉。
3. 作为运营者，我希望没有登录文件时看到「没有可用的小红书登录」，而不是去打公开页。
4. 作为运营者，我希望登录失效时停掉这一轮，避免后面的笔记继续打。

## 3. 范围

- 路由：`/xhs/notes`、`/xhs/notes/add`、`/xhs/notes/settings`。
- 识别笔记：`xiaohongshu.com/discovery/item/{id}`、`xiaohongshu.com/explore/{id}`，以及短链解析后落到这两类。
- 失败列表里已经存在的笔记不自动搬迁。
- 渠道名 `xhs_note`，和商品渠道 `xhs` 分开。调度任务 `xhs_note_monitor`。
- 频率可选每天、每周、每月，不提供每小时。默认 `0 9 * * *`，默认关闭。

不在本期：多账号轮换、改商品公开页采集、把失败列表里的旧笔记自动迁走。

## 4. 验收

1. 笔记链接不能进入商品表。
2. 同一天采集两次只有一行；没解析到的字段保留当天原值。
3. 没有小红书账号时不调用浏览器。
4. 列表展示最近一天，以及相对前一天的差值。没有前一天显示「—」。
